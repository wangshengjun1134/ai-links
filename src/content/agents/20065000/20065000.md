## 【产品概述】
Vidu Claw 定位为"你的第一个 AI 创意员工"，旨在通过先进的人工智能技术彻底重塑视频创作流程。其核心价值主张在于极简的操作体验，用户仅需输入简单的想法或指令，即可自动生成包含分镜、脚本与配乐的完整短片。该产品主要解决内容创作者缺乏制作预算、精力不足以及专业技能欠缺的痛点。无论是日常社媒更新还是复杂的电商推广，Vidu Claw 都能实现从创意构思到成品输出的无缝衔接，帮助用户即刻解锁无限场景可能性，大幅降低视频生产门槛，让想象随时发生。

## 【核心功能】
1. **文生视频**：支持直接将文本描述转化为高质量视频内容，无需额外素材，实现创意即时可视化。
2. **图生视频**：能将静态的产品图片或设计图瞬间转化为生动的实景短视频，赋予图片动态生命力。
3. **参考生视频**：基于提供的参考素材进行风格迁移或内容延伸生成，保持视觉一致性。
4. **Vidu Skills 集成**：支持通过对话安装技能，配置环境变量后直接调用 API 生成特定风格视频，扩展性强。
5. **模板库**：提供多种预设模板，帮助用户快速启动创作项目，显著提高内容生产效率和规范性。

## 【应用场景】
1. **社媒创作者**：针对需要每日更新短视频但缺乏制作预算和精力的个人创作者，自动生成完整短片。
2. **电商运营**：面对成千上万商品页面，将静态图转化为动态视频，真实展示产品魅力以吸引注意力。
3. **内容增长专家**：助力营销团队自动读取产品文档，提炼创意点并转化为适配 LinkedIn 或 YouTube 风格的演示视频。

## 【技术特点】
Vidu Claw 基于 UniDiffuser 多模态大模型技术构建，具备强大的内容理解与跨模态生成能力。其差异化特点在于支持 API 开放平台，允许开发者通过配置环境变量（如 VIDU_TOKEN 和 VIDU_BASE_URL）将 AI 能力集成至现有工作流中。系统采用智能化的积分扣除机制，根据内容任务类型消耗相应积分，确保资源合理分配。目前产品处于申请测试阶段，用户需提交申请并审核通过后即可使用。此外，通过集成 Vidu Skills，用户可直接通过对话调用复杂功能，实现了高度自动化的创意工作流，显著提升了技术落地的便捷性与灵活性，体现了其在多模态交互领域的技术优势。
