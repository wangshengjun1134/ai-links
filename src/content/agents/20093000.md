## 【产品概述】
OneClaw 是一款基于 OpenClaw 打造的个人 AI 助手桌面应用，旨在让用户无需具备编程基础即可享受 AI 自动化带来的便利。其核心价值主张在于"一键安装、开箱即用"，彻底告别复杂的命令行操作和环境配置。该产品主要解决用户在数据处理、网页交互及文件生成等方面的重复性劳动问题，通过自然语言指令让 AI 自动操控浏览器、读写文件并生成报告，极大提升了个人工作效率，实现了"用一句话让 AI 替你干活"的愿景，让 AI 真正落地于日常电脑操作中，降低了自动化任务的技术门槛。

## 【核心功能】
1.  **一键安装体验**：提供 DMG 或 EXE 安装包，双击即用，无需安装 Node.js、Git 等依赖。
2.  **多模型支持**：内置 Anthropic、Kimi、OpenAI、Google 及自定义 API 支持，灵活选择。
3.  **浏览器自动化**：AI 可自动打开浏览器、抓取数据、填写表单及完成复杂网页操作。
4.  **内嵌运行环境**：自带 Node.js 22 运行时，无需用户额外配置开发工具。
5.  **跨平台兼容**：支持 macOS 和 Windows 双平台，涵盖 ARM64 与 x64 架构。

## 【应用场景】
1.  **数据采集与整理**：如抓取小红书笔记并整理成 Excel 表格，适用于市场分析师。
2.  **自动化报告生成**：自动读取文件数据并生成分析报告，适用于办公人员。
3.  **复杂网页任务处理**：自动填写表单或执行多步骤网页操作，适用于运营人员。

## 【技术特点】
OneClaw 在技术架构上具有显著的差异化优势。首先，它采用了内嵌运行时技术，将 Node.js 22 环境打包进应用，消除了环境依赖冲突，确保了运行的稳定性。其次，针对中国网络环境进行了专项优化，预置了 npm 镜像源，用户无需翻墙即可顺畅安装和使用，解决了国内开发者常见的网络障碍。此外，产品基于 OpenClaw 开源项目构建，继承了其强大的 AI 代理能力，能够精准解析自然语言指令并转化为具体的浏览器操作指令。支持多种主流 LLM 提供商的 API 接入，保证了模型选择的灵活性和任务执行的智能程度，实现了本地桌面应用与云端大模型的高效协同，降低了技术使用门槛。
