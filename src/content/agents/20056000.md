## 【产品概述】
AiPy（爱派）是一款定位为"AI 员工"的智能助手产品，其核心价值主张在于"不止聊天，更能代劳"。与传统大模型仅能问答不同，AiPy 旨在解决用户需要实际执行计算机任务的问题。它通过结合 LLM 大模型与 Python 程序生态，让 AI 拥有操作电脑、手机及服务器的能力。用户只需下达工作要求，AiPy 即可自动规划、编码并执行任务，交付专家级成果，实现从"AI Think"到"AI Do"的转变。它让 AI 觉醒「战甲触手」，触发一场智能革命，使每个念头都能转化为实际成果，彻底改变人机交互方式。

## 【核心功能】
1. **医疗单据分析**：自动识别医院检查单照片，提取指标并分析病情，提供治疗建议及费用评估。
2. **视频语音提取**：调用本地 Vosk 模型，全自动分析视频文件，提取人声转文本，自动断句修正。
3. **自动化邮件报告**：读取用户需求，自动生成报告内容并编写脚本，实现定时邮件全自动发送。
4. **移动端设备控制**：自动连接手机，识别界面布局，执行如刷抖音等 APP 操作，无需人工干预。
5. **多音色语音生成**：输入文字即可生成含男女声等多种音色的商业级语音文件，调用本地开源模型。

## 【应用场景】
1. **个人数据分析**：适用于需要处理海量数据（如 22 万条数据）的个人或研究人员，快速完成分析任务。
2. **实验室监控**：适用于科研人员，分析红外监控实时情况（温度、亮度变化）并生成报告。
3. **测试与开发效率提升**：适用于测试人员生成功能测试用例，或非技术人员设计绘图插件，大幅提升工作效率。

## 【技术特点】
AiPy 基于创新的"Python-Use"范式，提出"No Agents, Code is Agent"理念。其技术优势在于不依赖大量预置 Agent 或 MCP Server，而是通过大模型理解任务后实时自动编码并执行 Python 代码。支持本地部署，确保敏感数据无需上传云端，保障数据安全隐私。模型兼容性强，支持所有通用大模型 API 及本地模型（如 Ollama），推荐高性价比的 DeepSeek。相比 Manus 等产品，AiPy 开源免费，Token 消耗更低，且具备控制局域网设备及内网数据库的能力。通过反馈机制不断完善迭代，最终实现 AI 与环境的交互完成任务，真正实现通用 AI Agent 是 NO Agents 的愿景。
