## 【产品概述】
智谱 AI 致力于构建新一代大模型全栈技术体系，核心定位为提供高效能模型服务与可信智能。作为国产原创 GLM 大模型架构的代表，其核心价值主张在于通过从训练层深度优化 Agent 核心能力，解决任务规划、数据稀缺和策略优化等核心难题。产品不仅生产模型，更构建可信智能，大幅提升工具调用与长链路执行能力，旨在用可信赖的 AI 让生活更美好，性能比肩国际顶尖模型水平，推动大模型 Agent 生态发展。

## 【核心功能】
1. **GLM-5 基座模型**：专为智能体工程推出的旗舰模型，在智能体编程核心榜单上达到开源模型 SOTA 性能。
2. **AutoGLM 智能体**：具备自主规划、推理与执行能力，解决了任务规划难题，具备持续自我改进能力。
3. **GLM-4.6V 视觉模型**：全球 100B 级效果出众的开源视觉推理模型，原生支持工具调用，支持 128K 长上下文。
4. **MaaS 平台服务**：提供能力全球领先、灵活易用、高性价比的全模态大模型 API 服务，开箱即用。
5. **全流程开发套件**：支持模型微调，低至十分钟完成微调，让模型更懂任务场景，保障企业级 AI 应用落地。

## 【应用场景】
1. **企业级定制开发**：利用全流程开发套件和模型微调功能，满足千行百业真需求，保障应用落地。
2. **个人办公提效**：通过智谱清言、GLM PPT/海报功能，一键生成精美文档，实现高保真情景化翻译。
3. **自动化任务执行**：AutoGLM 可自主执行超过 50 步的长步骤操作，支持跨 APP、跨设备无人驾驶式操作计算机。
