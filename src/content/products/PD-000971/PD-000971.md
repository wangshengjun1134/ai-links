## 【产品概述】

Nanobot 是一个开源框架，用于构建 MCP（Model Context Protocol）智能体。它能够将普通的 MCP 服务器包装成具有推理能力、系统提示、工具编排和丰富 MCP-UI 支持的智能代理。

## 【核心功能】

- MCP 原生框架：从底层支持 MCP 生态系统
- 每个代理都作为 MCP 服务器暴露
- MCP-UI 集成：支持在聊天客户端内直接渲染交互式 React 组件
- 可嵌入到任何应用或网站中
- 可利用每月新增的丰富 MCP 服务器生态系统

## 【应用场景】

可玩的游戏、购物车、仪表板、沉浸式聊天体验、生产级应用程序。

## 【技术优势】

开源、灵活、可扩展，社区驱动开发，支持系统提示和对话记忆，自主推理能力。
