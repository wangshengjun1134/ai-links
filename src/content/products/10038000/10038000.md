## 产品概述

Rytr 是一款 AI 写作工具，生成原创且引人入胜的内容，听起来像真人而非机器。拥有 800 万 + 满意用户，TrustPilot、G2 等平台 1000+ 条评价，评分 4.9/5。

## 核心功能

### AI 文本生成
- 40+ 内容用例和模板
- 包括邮件、SEO 元标题、评论回复、段落内容、社交媒体帖子和标题创意、行动号召等

### AI 自动完成
- 自动完成句子/段落
- 提升写作流畅度和质量

### 文本编辑
- 继续写作、内容扩展
- 句子缩短、改写生成

### 语法检查器
- 优化内容的清晰度、语法和语气

### 自定义语气
- 分析用户写作样本，模仿用户语气生成内容
- 可创建多个自定义语气

### 抄袭检查
- 确保内容原创性
- 提供抄袭检测功能

### 浏览器扩展
- Chrome 扩展程序
- 支持随时随地创作

### 多语言支持
- 支持 40+ 种语言

### API 接口
- 提供 API 服务
