## 【产品概述】

Goose 是一款本地 AI 智能体，能够无缝自动化工程任务。它由 Block 公司开源，旨在让开发者能够自由贡献、定制和创新。

## 【核心功能】

- 开源：内置透明度和协作性
- 本地运行：高效执行任务，保持用户掌控
- 可扩展：使用首选 LLM 定制，连接任何外部 MCP 服务器或 API
- 自主性：独立处理复杂任务，从调试到部署

## 【应用场景】

生成 API 测试的假数据、自动修复供应商响应错误、创建 Google Scripts、字符串本地化资源拆分、Dashboard 组件迁移到 React 等。

## 【技术优势】

开源支持开发者贡献，本地运行保持控制，可扩展支持自定义 LLM 和 MCP 服务器连接。
