## 【产品概述】
Replicate 是一个 AI 模型托管和 API 服务平台，已加入 Cloudflare。

## 【核心功能】
1. 运行 AI 模型（一行代码调用）
2. 微调模型（使用自有数据训练）
3. 部署自定义模型（通过 Cog 工具）
4. 自动扩展（根据流量自动伸缩）

## 【典型应用场景】
- 图像生成与编辑
- 视频生成
- 语音合成
- 音乐创作
- 图像修复
- 大语言模型应用
- 自主机器人
- AI 绘画等

## 【技术/竞争优势】
- 支持多种 GPU/CPU 硬件配置
- 按需付费，无流量不收费
- 生产就绪的 API
- 内置日志和监控功能
- 支持 Cog 开源工具打包模型
