# MCP思维工具服务器


一个模型上下文协议（MCP）服务器，实现了“思考”工具，以提高克劳德的复杂推理能力。


## 概述


此MCP服务器实现了Anthropic中描述的“思考”工具 [博客文章](https://www.anthropic.com/engineering/claude-think-tool)，这为克劳德在复杂的问题解决任务中提供了一个专门的结构化思维空间。该思考工具已被证明可以显著提高需要在长链工具调用中遵守策略和推理的复杂任务的性能。


## 特性


- **结构化思维空间**：为克劳德提供了一个专门的地方来分解复杂的问题
- **思想史**：维护所有想法的日志，并附上时间戳以供参考
- **统计与分析**：提供有关思维模式的元数据
- **清洁石板选项**：允许在重新开始时清除思维历史


## 安装


从PyPI安装：


BASH```
1pip install mcp-think-tool
```

## 配置


### 帆板运动


要在Windsurf中与Claude一起使用此工具，请将以下配置添加到MCP配置文件中：


JSON```
1
2
3
4
5
6
7
8"think": {
    "command": "/home/xxx/.local/bin/mcp-think-tool",
    "args": [],
    "type": "stdio",
    "pollingInterval": 30000,
    "startupTimeout": 30000,
    "restartOnFailure": true
}
```

这 `command` 字段应指向使用pip安装python包的目录。


### 码头工人


您可以仅使用Dockerfile安装此MCP服务器


首先下载Dockerfile，导航到它的目录，并构建Docker镜像


```
1docker build -t mcp-think-tool .
```

然后在MCP配置文件中添加以下配置


JSON```
1
2
3
4"think": {
    "command": "docker",
    "args": ["run", "--rm", "-i", "mcp-think-tool"]
}
```

这是经过测试和使用的 **克劳德桌面** 和 **光标**
