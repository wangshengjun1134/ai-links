# JavaFX模型上下文协议服务器


此模型上下文协议（MCP）服务器使大型语言模型（LLM）能够使用JavaFX primity绘制图形。


该服务器使用Quarkus MCP和JavaFX实现。


最初的想法和实施来自 [@孔茨德夫](https://gist.github.com/konczdev/5e6774d2d8640bf83baab88cb068bcc2)


[](https://www.youtube.com/watch?v=Wnh_-0dAaDI)


观看视频 [这里](https://www.youtube.com/watch?v=Wnh_-0dAaDI).


## 一般使用


1. 安装 [jbang的](https://www.jbang.dev/download/)
2. 配置您的MCP客户端以运行服务器 `jbang jfx@quarkiverse/quarkus-mcp-servers` （参见 Claude桌面配置 在…下面


## Claude桌面配置和 [mcp-cli](https://github.com/chrishayuk/mcp-cli)


将此添加到您的 `claude_desktop_config.json` 或 `server_config.json` 文件：


JSON```
1

  }
}
```

## 本机映像/可执行文件


鉴于JavaFX的依赖关系，目前jfx服务器无法编译为本机可执行文件。


使用GluonFX应该可以做到这一点，但现在留给读者练习。如果您对此感兴趣，请打开问题或PR。
