# E2B MCP服务器


[![](https://smithery.ai/badge/e2b)](https://smithery.ai/server/e2b)


此存储库包含 [苯甲酸雌二醇](https://e2b.dev) MCP服务器。


E2B MCP服务器允许您添加 [代码解释能力](https://github.com/e2b-dev/code-interpreter) 通过E2B沙盒连接到您的Claude Desktop应用程序。查看演示 [这里](https://x.com/mishushakov/status/1863286108433317958).


有两个版本：


- 脚本
- python


### 通过Smithery安装


您还可以通过以下方式自动为Claude Desktop安装E2B [史密瑟里](https://smithery.ai/server/e2b):


BASH```
1npx @smithery/cli install e2b --client claude
```
