# MCP Git 安装


[![](https://smithery.ai/badge/mcp-git-ingest)](https://smithery.ai/server/mcp-git-ingest)


一个模型上下文协议（MCP）服务器，帮助读取GitHub存储库结构和重要文件。


灵感来自 [吉廷斯特](https://gitingest.com/).


[![](https://gips2.baidu.com/it/u=111518437,1977938341&fm=3081&app=3081&f=PNG?w=760&h=400)](https://glama.ai/mcp/servers/un2zatig9e)
