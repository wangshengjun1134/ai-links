# 面向LLM的开放战略合作伙伴（OSP）营销工具


![](https://badge.mcpx.dev?type=server)


一套全面的工具，用于技术营销内容的创建、优化和产品定位，基于 [开放战略合作伙伴](https://openstrategypartners.com)“经过验证的方法。


该软件基于 [模型上下文协议（MCP）](https://openstrategypartners.com/blog/the-model-context-protocol-unify-your-marketing-stack-with-ai/) 并且可以由支持MCP的任何LLM客户端使用。


截至2025年2月初，支持MCP的LLM客户包括：


- [Claude桌面应用程序](https://claude.ai/download) 对于我们中技术含量较低的人来说，它是最容易使用的（它是由MCP的发明者制造的）。
- [光标IDE](https://www.cursor.com/) 在我们的开发者朋友中非常受欢迎。
- [Librechat](https://www.librechat.ai/) 是一款优秀的开源AI/LLM界面应用程序。


阅读我们的愿景文件，了解如何 [代理人工智能将有利于营销](https://openstrategypartners.com/blog/mastering-llm-interaction-preparing-marketing-teams-for-agentic-ai-success-with-mcp/).


## 特性


### OSP产品价值图生成器


生成结构化 [OSP产品价值图](https://openstrategypartners.com/the-osp-value-map/) 有效传达产品的价值和定位：


- 标语创建和细化
- 跨市场、技术、用户体验和业务维度的立场声明
- 角色、挑战和需求的人物角色开发
- 价值案例文档
- 特征分类和组织
- 特征、区域和类别的层次结构
- 完整性和一致性验证系统


### 2.OSP元信息生成器


为web内容创建优化的元数据：


- 文章标题（H1），关键字位置正确
- 针对搜索优化的元标题（50-60个字符）
- 具有明确价值主张的元描述（155-160个字符）
- SEO友好的URL蛞蝓
- 搜索意图分析
- 移动显示优化
- 点击查看费率提升建议


### 3.OSP内容编辑代码


应用 [OSP的语义编辑代码](https://openstrategypartners.com/resources/the-osp-editing-codes/) 全面内容审查：


- 范围和叙事结构分析
- 增强流动性和可读性
- 风格和措辞优化
- 单词选择和语法验证
- 技术准确性验证
- 包容性语言指导
- 通过前后示例生成建设性反馈


### 4.OSP技术写作指南


创建高质量技术内容的系统方法：


- 叙事结构发展
- 流程优化
- 风格指南
- 技术准确性验证
- 内容类型特定指南（教程、参考文档、API文档）
- 可访问性考虑因素
- 国际化最佳实践
- 质量保证检查表


### 5.OSP网页SEO指南


为搜索引擎和用户体验优化网络内容的综合系统：


- 元内容优化（标题、有字符限制的描述和关键字放置）
- 内容深度增强（子主题、数据集成、多格式优化）
- 搜索意图对齐（5种类型：信息、导航、事务、商业、本地）
- SEO技术实施（关键词研究、集成协议、内部链接规则）
- 结构化数据部署（常见问题解答、操作方法、产品模式）
- 内容推广策略（社交媒体、广告策略）
- 质量验证方案（建设性反馈、基于差异的修订系统）
- 性能衡量方法（点击率、跳出率、页面停留时间指标）

## 安装


### 先决条件


#### 视窗


1. 安装Claude Desktop（或其他启用MCP的AI工具）


- 下载 [Claude桌面版](https://claude.ai/download)
- 按照当前的安装说明进行操作： [安装克劳德桌面](https://support.anthropic.com/en/articles/10065433-installing-claude-for-desktop)
2. 安装Python 3.10或更高版本：


- 从下载最新的Python安装程序 [python.org](https://python.org)
- 运行安装程序，选中“将Python添加到PATH”
- 打开命令提示符并使用验证安装 `python --version`
3. 安装紫外线：


- 以管理员身份打开命令提示符
- 跑 `pip install --user uv`
- 通过以下方式验证安装 `uv --version`


#### macOS


1. 安装Claude Desktop（或其他启用MCP的AI工具）


- 下载 [Claude桌面版](https://claude.ai/download)
- 按照当前的安装说明进行操作： [安装克劳德桌面](https://support.anthropic.com/en/articles/10065433-installing-claude-for-desktop)
2. 安装Python 3.10或更高版本：


- 使用Homebrew： `brew install python`
- 通过以下方式验证安装 `python3 --version`
3. 安装紫外线：


- 使用Homebrew： `brew install uv`
- 或者： `pip3 install --user uv`
- 通过以下方式验证安装 `uv --version`
