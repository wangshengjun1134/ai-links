# ffmpeg mcp


一个stdio MCP服务器，用于与ffmpeg交互以进行常见的媒体操作。


该项目由以下机构赞助 [ChatWise](https://chatwise.app) -多功能LLM聊天机器人，支持MCP。


## 用法


你需要 [FFmpeg](https://www.ffmpeg.org/) 首先安装在您的系统上。


然后将以下命令添加到MCP客户端：


```
1npx -y ffmpeg-mcp
```

默认情况下，它使用 `ffmpeg` 从您的系统路径。您还可以指定路径 `ffmpeg` 通过设置 `FFMPEG_PATH` 环境变量，例如：


```
1FFMPEG_PATH=/path/to/ffmpeg
```
