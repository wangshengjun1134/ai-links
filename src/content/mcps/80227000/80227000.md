# Tripo MCP服务器


Tripo MCP为AI助手和 [Tripo AI](https://www.tripo3d.ai) 通过 [模型上下文协议（MCP）](https://github.com/anthropics/anthropic-cookbook/tree/main/mcp).


> **注：** 该项目处于alpha阶段。目前，它支持Tripo Blender插件集成。


## 特点


- 使用Tripo的API从自然语言生成3D资产并导入到Blender
- 与Claude和其他启用MCP的AI助手兼容


## 快速开始


### 先决条件


- Python 3.10+
- [搅拌机](https://www.blender.org/download/)
- [Tripo AI搅拌机插件](https://www.tripo3d.ai/app/home)
- Claude桌面或光标IDE


### 安装


1. 从以下位置安装Tripo AI Blender插件 [Tripo AI网站](https://www.tripo3d.ai/app/home)
2. 在Claude Desktop或Cursor中配置MCP服务器。


- `pip install uv`

### 用法


1. 启用Tripo AI Blender插件并启动Blender mcp服务器。
2. 使用光标或claude聊天。例如，“生成未来椅子的3D模型”。
