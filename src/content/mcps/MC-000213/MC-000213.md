# MCP文件系统


一种通过标准化接口提供文件系统操作的模型上下文协议（MCP）服务器。


## 特性


- 文件操作（读/写）
- 目录管理（创建/列出/删除）
- 文件移动和重命名
- 文件元数据检索
- 文件搜索功能
- 通过允许的目录进行访问控制


## 入门指南


1. 安装依赖项：


BASH```
1npm install
```

1. 构建项目：


BASH```
1npm run build
```

1. 使用允许的目录运行服务器：


BASH```
1npm start /path/to/allowed/directory [/path/to/another/directory ...]
```

## 发展


服务器是使用以下方式构建的：


- TypeScript
- MCP SDK（高级API）
- Node.js文件系统API


## 安全


服务器实施路径验证，以确保操作仅在启动时指定的允许目录内进行。
