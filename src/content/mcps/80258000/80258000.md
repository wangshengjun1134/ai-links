## 快速开始


### 1.获取您的API代币


首选[https://id.atlassian.com/manage-profile/security/api-tokens并创建令牌。](https://id.atlassian.com/manage-profile/security/api-tokens%E5%B9%B6%E5%88%9B%E5%BB%BA%E4%BB%A4%E7%89%8C%E3%80%82)


> 对于服务器/数据中心，请改用个人访问令牌。看 [认证](https://mcp-atlassian.soomiles.com/docs/authentication).


### 2.配置IDE


添加到您的Claude Desktop或Cursor MCP配置中：

        "CONFLUENCE_URL": "https://your-company.atlassian.net/wiki",

        "CONFLUENCE_API_TOKEN": "your_api_token"
      }
    }
  }

```

> **服务器/数据中心用户**：使用 `JIRA_PERSONAL_TOKEN` 而不是 `JIRA_USERNAME` + `JIRA_API_TOKEN`。参见 [认证](https://mcp-atlassian.soomiles.com/docs/authentication) 了解详情。

## 兼容性


| 产品 | 部署 | 支持 |
| --- | --- | --- |
| Confluence | 云 | 完全支持 |
| 汇流 | 服务器/数据中心 | 支持（v6.0+） |
| Jira | 云 | 完全支持 |
| Jira | 服务器/数据中心 | 支持（v8.14+） |


## 关键工具


| Jira | 汇流 |
| --- | --- |
| `jira_search` -使用JQL搜索 | `confluence_search` -使用CQL搜索 |
| `jira_get_issue` -获取问题详细信息 | `confluence_get_page` -获取页面内容 |
| `jira_create_issue` -创建问题 | `confluence_create_page` -创建页面 |
| `jira_update_issue` -更新问题 | `confluence_update_page` -更新页面 |
| `jira_transition_issue` -更改状态 | `confluence_add_comment` -添加评论 |


**总共72个工具** --请参阅 [工具参考](https://mcp-atlassian.soomiles.com/docs/tools-reference) 查看完整列表。
