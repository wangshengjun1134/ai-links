# 获取mcp


用于获取URL/Youtube视频转录的MCP服务器。


该项目由以下机构赞助 [ChatWise](https://chatwise.app)，一个具有一流MCP支持的一体化LLM聊天机器人。


## 用法


BASH```
1
2
3
4
5
6
7
8# stdio server
npx -y fetch-mcp
# sse server
npx -y fetch-mcp --sse
# streamable http server at /mcp
npx -y fetch-mcp --http
# custom endpoint
npx -y fetch-mcp --http /my-mcp
```

## 工具


### fetch_url


获取URL，可以返回HTML或Markdown（默认）。


### fetch_youtube_transcript


获取Youtube成绩单。
