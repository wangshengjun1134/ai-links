# MCP Reddit服务器


[![](https://smithery.ai/badge/@adhikasp/mcp-reddit)](https://smithery.ai/server/@adhikasp/mcp-reddit)


A. [模型上下文协议（MCP）](https://modelcontextprotocol.io/introduction) 提供获取和分析Reddit内容的工具的服务器。


[![mcp-reddit MCP server](https://gips2.baidu.com/it/u=1457782124,760855486&fm=3081&app=3081&f=PNG?w=760&h=400)](https://glama.ai/mcp/servers/3cg9gdyors)


## 特性


- 从任何子版块获取热门话题
- 获取详细的帖子内容，包括评论
- 支持不同的帖子类型（文本、链接、图库）


## 安装


### 通过Smithery安装


通过以下方式自动安装Claude Desktop的Reddit内容 [史密瑟里](https://smithery.ai/server/@adhikasp/mcp-reddit):


BASH```
1npx -y @smithery/cli install @adhikasp/mcp-reddit --client claude
```

### 手动安装


JSON```
1
2
3
4
5
6
7{
  "reddit": {
    "command": "uvx",
    "args": ["--from", "git+https://github.com/adhikasp/mcp-reddit.git", "mcp-reddit"],
    "env": {}
  }
}
```
