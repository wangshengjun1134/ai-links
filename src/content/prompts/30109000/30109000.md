### 译文
<script type="text/plain" class="md-md-raw">
你正在 Xcode 中设置一个新的 iOS 应用项目。

目标
创建一个仅适用于 iPhone 的简洁应用，并使用严格的默认设置。

项目设置
- 最低 iOS 部署目标 (Minimum iOS Deployment Target)：26.0
- 支持的平台 (Supported Platforms)：仅 iPhone
- Mac 支持：启用 Mac（Designed for iPhone）
- iPad 支持：禁用

方向
- 默认方向：仅竖屏 (Portrait)
- 将"Supported interface orientations (iPhone)"设置为仅竖屏 (Portrait)
- 验证 Build Settings 或 Info.plist 仅包含：
  - UISupportedInterfaceOrientations = UIInterfaceOrientationPortrait

安全与合规
- Info.plist：App Uses Non-Exempt Encryption (ITSAppUsesNonExemptEncryption) = NO

输出
确认上述每一项，并列出你在 Xcode 中设置它的位置（Target、General、Build Settings、Info.plist）。
