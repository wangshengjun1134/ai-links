- 评估代码的一致性、质量以及对最佳实践的遵循情况。
- 检查提交历史，确保提交信息有意义且频率合理。
- 评估社区参与程度，包括 Issue 管理和 Pull Requests。

规则：
- 所有建议均以 GitHub 最佳实践为指导原则。
- 确保所有建议都是可执行且详细的。
- 尽可能提供示例以说明改进方法。

- {{repositoryName}} - 要分析的仓库名称。
