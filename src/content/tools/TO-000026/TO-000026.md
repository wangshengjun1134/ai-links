# 股票分析

分析股票价格走势并提供投资建议。

## 支持的市场

| 市场 | 代码格式 | 示例 |
|------|----------|------|
| A股（上海） | XXXXXX.SH | 600519.SH（茅台） |
| A股（深圳） | XXXXXX.SZ | 000001.SZ（平安） |
| 港股 | XXXX.HK | 0700.HK（腾讯） |
| 美股 | TICKER | AAPL, TSLA, NVDA |

## 分析工作流程

当被要求分析某只股票时：

1. 使用网络搜索查询当前价格数据
   - 查询格式："{股票名称} 股价 今日" 或 "{TICKER} stock price today"
   - 查找：当前价格、开盘价、最高价、最低价、成交量、涨跌幅

2. 收集额外背景信息（如有）
   - 影响该股票的近期新闻
   - 行业趋势
   - 市场情绪

3. 以结构化格式呈现分析：

```markdown
## 📊 {股票名称}({代码}) 股价分析

### 📈 核心数据
| 指标 | 数值 | 变化 |
|------|------|------|
| 收盘价 | XXX | +XX |
| 涨跌幅 | XX% | 🔴/🟢 |
| 最高/最低 | XX / XX | - |
| 成交量 | XX万手 | - |

### 技术面分析
- 短期趋势：...
- 关键支撑/压力位：...
- 均线状态：...

### 💡 投资建议
**建议：买入/持有/卖出**
- 理由：...
- 操作策略：...
- 风险提示：...
```

## 建议指南

### 买入信号

- 突破关键阻力位
- 成交量放大配合上涨
- 均线多头排列
- 基本面利好

### 持有信号

- 趋势不明确
- 等待关键突破
- 已有持仓且趋势良好

### 卖出信号

- 跌破关键支撑位
- 成交量萎缩
- 均线空头排列
- 基本面恶化

## 风险免责声明

必须包含："分析仅供参考，不构成投资建议。投资有风险，入市需谨慎。"
