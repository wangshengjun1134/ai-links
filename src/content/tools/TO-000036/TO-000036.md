# SONOSCLI

**版本**: v1.0.0  
**作者**: Peter Steinberger · @steipete  
**协议**: MIT-0

---

## 描述

Control Sonos speakers (discover/status/play/volume/group).

---

## 运行要求

- **平台**: Clawd
- **二进制文件**: `sonos`

---

## 安装说明

```bash
go install github.com/steipete/sonoscli/cmd/sonos@latest
```

---

## 使用方法

Use sonos to control Sonos speakers on the local network.

### 快速开始

```bash
sonos discover
sonos status --name "Kitchen"
sonos play|pause|stop --name "Kitchen"
sonos volume set 15 --name "Kitchen"
```

### 常用任务

```bash
# 分组操作
sonos group status|join|unjoin|party|solo

# 收藏夹
sonos favorites list|open

# 队列管理
sonos queue list|play|clear

# Spotify 搜索 (通过 SMAPI)
sonos smapi search --service "Spotify" --category tracks "query"
```

---

## 注意事项

- 如果 SSDP 发现失败，可指定 `--ip <speaker-ip>`
- Spotify Web API 搜索为可选功能，需要设置 `SPOTIFY_CLIENT_ID` 和 `SPOTIFY_CLIENT_SECRET` 环境变量
